## Defensibility assessments

- Kong Konnect integration plus existing test collections and enterprise storage policies create workflow switching costs; protocol clients alone are easy to replace. [1](https://insomnia.rest/pricing)

## Three product reasons to consider it

1. Debug REST, GraphQL, gRPC, WebSocket and other protocols in a single client. [1](https://insomnia.rest/pricing)
2. Choose local, Git or encrypted cloud storage for collections and project collaboration. [1](https://insomnia.rest/pricing)
3. Lint OpenAPI designs and execute scripted API tests through the Inso CLI. [1](https://insomnia.rest/pricing)
