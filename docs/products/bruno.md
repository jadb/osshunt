## Defensibility assessments

- Portable collection formats and existing Git workflows encourage adoption but also limit proprietary lock-in; accumulated collections and extensions provide modest workflow stickiness. [1](https://docs.usebruno.com/introduction/getting-started)

## Three product reasons to consider it

1. Keep readable API collection files beside application code and review changes through Git. [1](https://docs.usebruno.com/introduction/getting-started)
2. Develop API requests locally without an account or mandatory synchronization service. [1](https://docs.usebruno.com/introduction/getting-started)
3. Reuse scripted assertions and collection runs in a command-line CI workflow. [1](https://docs.usebruno.com/introduction/getting-started) [2](https://docs.usebruno.com/bru-cli/installation)
