- Established plugins, scene workflows and broadcast integrations support ecosystem stickiness; open source keeps the core forkable. [1](https://obsproject.com/)

## Three product reasons to consider it

1. Scene collections combine windows, cameras, browser sources and media into a live composition. [1](https://obsproject.com/)
2. Audio mixer filters and per-source controls shape broadcast sound. [1](https://obsproject.com/)
3. Studio Mode previews scene changes before switching the live output. [1](https://obsproject.com/)
