- Widely adopted diagram syntax and integrations create ecosystem familiarity; MIT code and text portability limit proprietary control. [1](https://mermaid.js.org/intro/)

## Three product reasons to consider it

1. Text-defined diagrams can be reviewed and versioned alongside documentation. [1](https://mermaid.js.org/intro/)
2. Multiple diagram grammars cover sequences, classes, ER models and flowcharts. [1](https://mermaid.js.org/intro/)
3. JavaScript embedding renders diagrams dynamically inside documentation pages. [1](https://mermaid.js.org/intro/)
