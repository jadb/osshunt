## Defensibility assessments

- Native format breadth and integrated audio/video tools create practical workflow value; open formats and code limit lock-in. [1](https://shotcut.org/features/)

## Three product reasons to consider it

1. Native mixed-format timelines combine frame rates and resolutions without import conversion. [1](https://shotcut.org/features/)
2. HDR/10-bit processing supports higher-dynamic-range video workflows. [1](https://shotcut.org/features/)
3. Subtitle creation/import/export and speech-to-text integrate caption work with editing. [1](https://shotcut.org/features/)
