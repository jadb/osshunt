1. Universal Directory brings profiles from AD, LDAP and HR systems into a unified identity model. [1](https://www.okta.com/pricing/)
2. Lifecycle Management and Workflows automate employee onboarding, offboarding and access changes. [1](https://www.okta.com/pricing/)
3. Access Gateway extends identity policies to existing on-premises applications. [1](https://www.okta.com/pricing/)
