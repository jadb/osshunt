## Three product reasons to consider it

1. Code-linked error context and suspect commits help identify the change that introduced a failure. [1](https://sentry-blog.sentry.dev/sentry-raises-series-b/)
2. Monitoring spans supports investigating performance behavior alongside errors. [1](https://www.sentry.help/en/articles/13964853-how-is-my-legacy-plan-changing-september-12-2024)
3. Cross-platform error monitoring serves browser, mobile and backend teams in a common triage workflow. [1](https://sentry-blog.sentry.dev/sentry-raises-series-b/)
