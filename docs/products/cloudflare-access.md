1. Contextual policies combine identity groups, device posture, location and session controls for application access. [1](https://www.cloudflare.com/sase/products/access/)
2. Clientless web access and browser-based SSH/VNC serve contractors and infrastructure sessions. [1](https://www.cloudflare.com/sase/products/access/)
3. Service-token and mTLS authentication cover automated services and certificate-authenticated clients. [1](https://www.cloudflare.com/sase/products/access/)
