## Defensibility assessments

- Long-running community and reusable image-editing workflows provide durable ecosystem value; open code limits exclusive technical defensibility. [1](https://www.gimp.org/release-notes/gimp-3.2.html)

## Three product reasons to consider it

1. Linked layers refresh externally edited image assets inside a composition. [1](https://www.gimp.org/release-notes/gimp-3.2.html)
2. Editable vector layers preserve path geometry during transforms. [1](https://www.gimp.org/release-notes/gimp-3.2.html)
3. Nondestructive filter stacks and group effects enable revisable photo adjustments. [1](https://www.gimp.org/release-notes/gimp-3.2.html)
