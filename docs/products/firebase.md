## Defensibility assessments

- SDK integration across authentication, databases and app tooling raises application migration effort once APIs and data models are adopted. [1](https://firebase.google.com/products-build)

## Three product reasons to consider it

1. Realtime Database synchronizes user data online and offline for responsive apps. [1](https://firebase.google.com/products-build)
2. Authentication supports multiple sign-in providers in a shared app platform. [1](https://firebase.google.com/products-build)
3. App Check attestation helps distinguish legitimate app traffic from abusive backend requests. [1](https://firebase.google.com/products-build)
